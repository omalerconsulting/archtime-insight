# מערכת ניהול שעות ופרויקטים – משרד אדריכלים

בנייה בשלבים: שלב א׳ = ליבה מלאה (נוכחות, פרויקטים, תחנות תשלום, דוחות, דשבורד, הרשאות). שלב ב׳ = סימולציית שכר, חגים/ימי בחירה, שליחה אוטומטית לרו״ח.

## הרשאות וכניסה
- כניסה באימייל וסיסמה בלבד, ללא הרשמה עצמית. רק מנהל יוצר/מוחק משתמשים.
- שני תפקידים: `admin`, `employee`, בטבלת תפקידים נפרדת. המשתמש הראשון מוגדר מנהל אוטומטית, וכל מנהל יכול להעניק/לשלול הרשאת מנהל למשתמשים נוספים (ללא הגבלת מספר מנהלים).
- נתוני שכר, הכנסות ורווחיות גלויים למנהלים בלבד.

## ממשק העובד
- שעון נוכחות: כניסה/יציאה, כולל תיקון ידני.
- הפסקות והיעדרויות: חופשה, מחלה, מילואים, נסיעת עבודה, חג, יום בחירה, אחר.
- הזנת שעות לפי פרויקט: לכל יום, שורות של פרויקט + תיאור + שעות. כל עובד מזין בנפרד, וכמה עובדים יכולים לעבוד על אותו פרויקט — הצבירה נעשית ברמת הפרויקט (סכום כל השעות מכל העובדים), וגם ברמת עובד×פרויקט.
- התרעה כשסך שעות הפרויקטים ליום ≠ שעות הנוכחות.
- תצוגה חודשית עם סיכומים: שעות רגילות, נוספות 125%/150% לפי חוק, ימי היעדרות.
- הורדה/הדפסה של דוח חודשי מפורט ומסכם (RTL).
- העובד רואה רק את עצמו.

## פרויקטים ותחנות תשלום
שדות פרויקט: שם, **מספר קוד פרויקט** (ייחודי, לפי שיטת המספור במשרד), לקוח, סטטוס (פעיל/הושלם/בהמתנה), שכר כולל למשרד, תקציב שעות, תאריך התחלה.
- **תחנות תשלום (Milestones)**: לכל פרויקט רשימת תחנות — תיאור (חתימת חוזה, קבלת היתרים, עלייה לשטח...), סכום המוגדר **באחוזים או בסכום קבוע**, תאריך יעד (לו״ז), סטטוס (טרם הגיע / הגיע לגבייה / שולם) ותאריך תשלום.
- מסך "כספים בחוץ": כל הפרויקטים הפעילים, השלב הנוכחי, יתרה לגבייה וסה״כ חוב פתוח במשרד — עם תצוגת הדפסה מסודרת לישיבות הנהלה.
- **חריגת לו״ז**: תחנה שעברה את תאריך היעד ולא הושלמה מסמנת את הפרויקט באדום בממשק המנהל, עם מספר ימי החריגה ורשימת התחנות החורגות.

## דשבורד ניהולי
- שעות לפי פרויקט (סכום כלל העובדים), דירוג צרכני השעות.
- רווחיות לפרויקט: הכנסה בפועל/צפויה מול עלות שעות.
- מטריצת עובד×פרויקט והיקפי שעות.
- ניצול מול תקציב שעות, מגמה חודשית, שעות לא משויכות.
- מצב גבייה: שולם מול פתוח, חריגות לו״ז.
- **ניתוחי עובדים**: חריגות שעות (מעל/מתחת לתקן), שעות נוספות חריגות, אחוז שעות משויכות לפרויקט (יעילות דיווח), תפוקה ממוצעת לעובד לפרויקט, ימי היעדרות חריגים, עובדים ללא דיווח.
- כל התצוגות ניתנות להדפסה.

## עלות ורווחיות
עלות שעה = תעריף שהמנהל קבע לעובד; אם לא הוגדר — השכר השעתי שהעובד הזין.

## עיצוב, נגישות והדרכה
- עיצוב נקי ואיכותי, עברית RTL מלאה, מצב בהיר/כהה.
- העלאת לוגו המשרד בראש המערכת.
- תוסף נגישות תואם ת״י 5568: הגדלת טקסט, ניגודיות, גופן קריא, הדגשת קישורים, עצירת אנימציות, ניווט מקלדת, הצהרת נגישות.
- מסכי הוראות הפעלה נפרדים לעובד ולמנהל.

## שלב ב׳
- לוח חגי ישראל וערבי חג, ימי בחירה עם הסבר הזכאות לפי חוק.
- סימולטור שכר: שעות נוספות, פנסיה, קרן השתלמות, ביטוח לאומי, מדרגות מס, נקודות זיכוי, בונוסים חד־פעמיים.
- שליחת דוחות לרו״ח: הורדה ושליחה ידנית + משלוח אוטומטי בתאריך קבוע לכתובת שהמנהל מגדיר.

## פרטים טכניים
- Lovable Cloud (Postgres + Auth + Storage) עם RLS: עובד רואה רק את רשומותיו; שדות כספיים נחשפים רק דרך פונקציות שרת המאמתות תפקיד מנהל בטבלת התפקידים.
- טבלאות: `profiles`, `user_roles`, `projects`, `project_milestones`, `time_entries`, `project_hours`, `absences`, `org_settings`; בשלב ב׳ `holidays`, `payroll_settings`.
- אגרגציות הדשבורד בצד השרת (וויוז/שאילתות מקובצות) לתמיכה ב-150 פרויקטים.
- דוחות: תבניות הדפסה ייעודיות RTL ל-PDF, וייצוא Excel לרו״ח.
