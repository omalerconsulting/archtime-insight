# Project Compass

אני צריך שתחשוב כמו מתכנת מקצועי ואני צריך לבנות תוכנה לניהול שעות עובדים וניהול שעות בפרוייקטים במשרד אדריכלים. 

העובד צריך לחתום כניסה ויציאה, לעדכן הפסקות/חופשים/נסיעות וכל היעדרות מהעבודה ובמקביל צריך שניתן יהיה לסכום את השעות לפי פרוייקט. יש במשרד כ-150 פרוייקטים בכל רגע נתון וצריך שהתוכנה תאפשר הכנסת שעות אדריכל בכל פרוייקט על מנת שנוכל לאמוד את הזמנים שהשוקעו בכל פרוייקט ולחשב רווחיות של הפרוייקט. החלוקה היא לפי חודשי עבודה ולפיהם יצטרכו להכניס את הזמני עבודה שלהם. תתאפשר לכל עובד להוריד להדפסה דוח שעות מפורט ומסכם לכלל שעות העבודה שלהם באותו החודש ולהדפיסו ולהעביר למנהל.

במקביל, צריך שהמערכת תבצע ניתוחים של הפרוייקטים ותייצר דשבורד ניהולי שמאפשר למשתמש עם גישה של מנהל בלבד בכל רגע נתון לצפות בו, לראות איזה פרוייקט צורך הכי הרבה שעות, רווחיות לכל פרוייקט, סה"כ שעות מושקעות בכל פרוייקט, עובדים והיקפי שעות העבודה שלהם בכל פרוייקט וכל ניתוח נוסף שיכול לעזור למנהל לקבל החלטות יעילות לניהול המשרד.

העובדים-צריכים להזין שעות עבודה, שעות כניסה ויציאה כולל היעדרויות לפי האפשרויות שציינתי למעלה, בלבד. 

המנהל יוכל להוסיף/למחוק פרוייקטים במערכת. הוא יוכל לעדכן הכנסה מכל פרוייקט והמידע יישאר חשוף רק למשתמש שיהיו לו הרשאות מנהל. 

המנהל יוכל להיכנס לדשבורד הניהולי ולראות את הניתוחים בכל רגע נתון ולקבל מידע עדכני.

המנהל יוכל להדפיס ו/או לשלוח במייל לרואה החשבון שלו את פירוט שעות העובדים כשכל עובד יוצג בנפרד עם פירוט שעות העבודה שלו.

מבחינה עיצובית יש להקפיד על רמה עיצובית גבוהה, נקיה ואיכותית. שהכל יהיה ברור ונגיש ושיהיו הוראות הפעלה בסיסיות לכל אחד מסוגי המשתמשים. הכניסה למערכת תהיה אך ורק עם שם משתמש וסיסמה וכל משתמש שיפתח במערכת יוכל להיכנס. הרשאות הוספה/הורדה של משתמשים במערכת יהיו רק למי שיקבל הרשאות מנהל.

כחלק מהעיצוב, צריך לאפשר להוסיף לוגו של המשרד בראש התוכנה.

צריך להוסיף תוסף נגישות התואם את דרישות החוק במדינת ישראל.

דיווח השעות צריך להיות לפי חוקי הדיווח במדינת ישראל.

יש להזין למערכת את כלל החופשים והחגים כפי שמוגדרים. כלל חגי ישראל.

ימי בחירה המוגדרים בחוק יסומנו כימי בחירה במערכת. 

ליד ימי בחירה יופיע הסבר עם הוראות החוק לגביי ימי הבחירה והזכאות להם. 

בממשק העובד, כל עובד יוכל להזין את השכר השעתי שלו ויוכל לעשות סימולציה של משכורת בהתבסס על תנאיו. יש לאפשר מקום להגדרת אחוזי הפרשה לפנסיה, קרן השתלמות. תחשיבי הרשויות יעשו בצורה אוטומטית בהתאם לשכר ולפי החוק במדינה ומדרגות המס הקבועות בחוק. צריכה גם להיות התייחסות לנקודות זכות למס הכנסה והתחישוב של הסימולציית שכר יעשה בהתאם. 

בונוסים חד פעמיים גם אותן ניתן יהיה להזין למערכת.
